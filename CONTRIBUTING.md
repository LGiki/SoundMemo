# Contributing

Thanks for contributing to SoundMemo.

## Development

1. Open the project in Android Studio or build from the command line.
2. Run `./gradlew :app:assembleDebug` before submitting changes.
3. Keep recording and playback behavior local-first and privacy-preserving.
4. Prefer small, focused pull requests.

## Code Style

- Kotlin-first implementation.
- Jetpack Compose for UI.
- Material 3 components for interface consistency.
- Coroutines and Flow for async state.
- Room for recording metadata.
- DataStore for settings.
